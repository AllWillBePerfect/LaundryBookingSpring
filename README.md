# LaundryBookingService

Сервис бронирования стиральных машин. Пользователь бронирует свободный слот, администратор подтверждает или отклоняет заявку. Тема взята из реальной ситуации (см. «Контекст»). Проект учебный: и для изучения самого Spring, и для практики тестирования бэкенда.

## Контекст

В общежитии несколько человек сдают свои стиральные машины в аренду. Сейчас запись идёт через общий чат: желающий скидывает скриншот перевода и сообщение с датой и временем (например, «20.07 15:00»), а администратор в течение дня вручную ведёт и правит одно сообщение со списком записей.

Неудобства такого процесса: свободное время не видно, пользователь ждёт ответа администратора, а сам администратор вручную сверяет оплаты и держит список в актуальном виде.

## Требования

Сервис должен закрыть этот сценарий:

- пользователь сам смотрит свободные слоты, без ожидания администратора.
- бронирование по единому шаблону, заявка на слот и подтверждение оплаты.
- администратор видит заявки в своём интерфейсе, сверяет оплату, подтверждает или отклоняет их.
- список занятости обновляется сам, без ручного редактирования сообщения.

Сам сервис это логика и API. Интерфейс к нему может быть любым. В планах добавить бота в Telegram.

## Стек

- Java 21, Spring Boot 4.1
- PostgreSQL, Flyway
- Gradle, многомодульная сборка
- Spring Security, JWT
- JUnit 5, Mockito, Testcontainers

## Модули

Построен по принципу портов и адаптеров.

- `core`: домен и бизнес-логика.
- `persistence`: репозитории на JPA, миграции Flyway.
- `rest-app`: REST API, JWT, запускаемый модуль.
- `web-app`: веб-интерфейс на Thymeleaf, в планах.
- `telegram-app`: бот в Telegram, в планах.

## Функциональность

- Регистрация и вход по паролю и через Telegram.
- JWT с refresh-токенами.
- Бронирование слота с защитой от двойной брони.
- Блокировка слотов.
- Подтверждение и отклонение броней администратором.

API под префиксом `/api/v1`.

## Запуск

Нужны JDK 21 и Docker. База поднимается автоматически через docker-compose.

```
./gradlew :rest-app:bootRun
```

API на `http://localhost:8080/api/v1`.

## Тесты

По уровням пирамиды:

- юнит (`core`) на Mockito,
- интеграционные (`persistence`) на Testcontainers,
- веб-слой (`rest-app`, `@WebMvcTest`),
- сквозные (`rest-app`, `@SpringBootTest`).

```
./gradlew test
```

Интеграционным и сквозным тестам нужен Docker.
